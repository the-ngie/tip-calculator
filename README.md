# Tip Calculator
A simple javascript web that helps users quickly calculate tips and total bills. This project is built with HTML, CSS, and JavaScript.

 **Features**
- Enter your bill amount.
- Select a tip percentage (10%, 15%, or 20%) with clickable buttons.
- Instant calculation of tip and total amount.
- Input validation for empty or invalid values.
- Responsive and clean user interface.

**How It Works?**
1. The user enters a bill amount in the input field.
2. The user clicks one of the tip percentage buttons.
3. JavaScript calculates the tip and total bill.
4. The result is displayed on the page dynamically.
